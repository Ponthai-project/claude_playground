## 1. 依頼

殿より、信託銀行のデジタルアセット部門の人への質問機会（今後の部署異動にも関わる）を控え、事前に業務知識を得るための資料をグラレコ調アーティファクトで作成せよとの依頼。カバー範囲は殿指定の6点：①信託銀行のDA業務とは ②ステーブルコインの基礎と業界動向 ③資産の電子化・電子取引 ④ブロックチェーンの基礎と技術・DA業務での使われ方 ⑤その他学ぶべきこと ⑥面談で聞くと良いこと。

## 2. 前提・制約

- 読み手：金融の基礎素養はあるがDA分野は初学。異動は「検討段階」（面談で開始時に確認）。
- 深さ：殿の指定で「実務・専門を厚めに」。
- 形式：単一自己完結HTMLのグラレコ（skill `graphreco-html`）、CSP厳守・外部参照ゼロ。
- 制度が動く分野（2023〜2026で連続改正・実証）ゆえ最新誤認が最大リスク。全事実に時点併記、施行済／検討中／実証を峻別。
- 出力先：`claude_playground\信託銀行デジタルアセット業務_学習グラレコ.html`（当初GitHub直下に作成後、殿のご指示で claude_playground 配下へ移設）。

## 3. 検討した選択肢

| 論点 | 採用案 | 却下案と理由 |
|---|---|---|
| 章立ての軸順 | 業務→制度→技術（02業務→03/04制度→05技術） | 技術巻頭案：金融素養者には「業務の意義」が先の方が刺さる。技術先行は意義が見えにくく却下 |
| グローバル動向の扱い | 各論点内に対比の数行で溶かす | 独立章案：主対象が日本の信託銀行。独立章は面積の無駄で却下 |
| 調査の順序 | 制度→基盤→各社事例→数値→海外（土台から枝葉） | 各社事例先行案：土台未定で事例の位置づけを誤る危険。却下 |
| 成果物形式 | 単一HTML（一枚地図） | 複数ページ分割案：面談前に一望できる価値が高く、分割は目的に反し却下 |
| グラレコのティア | ティアA（軽量・システムフォント＋SVG） | ティアB（手描きフォント埋込）：ビルド一工程を要し、可読性・情報密度優先で殿がAを選択 |
| 質問リスト（07）の方向 | 将来性・組織・適性・キャリアを厚く | 実務・体制寄り：異動が「検討段階」のため、賭ける価値の見極めに資する将来性・適性を厚くした |
| 強調色のコントラスト | テラコッタを #C15F3C→#B4502E に微暗化 | パレット規約値の厳守：AA未達（実測3.4〜4.1:1）を内藤が指摘。可読性を優先し同系で微調整 |

## 4. 決定と決め手

「面談で恥をかかず、良い質問ができる」水準を上限に、**業務→制度→技術の9ブロック・ティアA・日本制度主軸**で作成した。決め手は、読み手が金融素養者かつ異動検討段階であること——**仕事の意義（業務）から入り、最重要ブロックを07（質問集）に置く**ことが、面談突破と異動判断の双方に最も直接効くと判断したため。深さは殿指定に従い実務寄りに振り、正確性リスク（動く制度）は全事実の時点併記で抑えた。

## 5. やったこと

- 勘助に方針策定＋検索戦略を策定させ、殿の承認（深さ・異動段階）を得た。
- 馬場が一次情報を調査（制度・基盤Progmat/ibet/START・主要3信託・市場規模・海外）、確度と時点を付して報告。
- 信玄がgraphreco skillでHTMLを段階Write／Editで構築（9ブロック、図解7型：流れ/対比/階層/場面を関係種別で使い分け、全SVGに揺らぎフィルタ）。
- render_html.pyで実レンダリング目視検分。内藤が事実・数値・可読性・レイアウトを検証。
- 内藤指摘の「中」4件を反映：04節の数値時点併記、01節の法律用語を正式名に統一、`.bench-flex`のflex欠落補修、強調色のコントラスト改善。
