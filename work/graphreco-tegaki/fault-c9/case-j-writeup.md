# C9書き出し検品記録（case-j）

対象：`fault\base.html` において「図解を置かなかった節」（現状の分類で `data-fig-type` を持たない節）8節分。
各節1行、その節に図示すべき関係（順序・因果・位置づけ・量比・対比・階層）が無いと判断した理由を記す。

1. **01 ひとことで言うと**：3つの吹き出しは並列的な要約フレーズであり、相互に順序・因果・量比の関係を持たない単純な並列列挙のため、図解を要しない。
2. **03 コスト対性能**：実体としては散布図（軸2本・3点プロット・矢印）を備えるが、当該要素が `data-fig-type` 属性を持たないため現状の分類では「図解なし節」に数えられている（分類側の既知の齟齬。詳細は `fault-NOTES.md` 参照）。
3. **05 科学でひと伸び**：2件の独立した数値（有機化学・タンパク質タスク）を個別の棒でそれぞれ示すのみで、両者間に比較・因果・順序の関係は無いため、図解を要しない。
4. **06 新機能（β）**：2つのベータ機能はそれぞれ独立した機能説明であり、並列関係以外の構造（順序・因果・階層等）を持たないため、図解を要しない。
5. **07 得意な7領域**：7つの領域は対等な列挙であり、相互の順序・階層・量比を持たないため、図解を要しない。
6. **08 価格とスピード**：価格2種・速度2種はいずれも単発の数値提示であり、対比や量比の構造を伴わないため、図解を要しない。
7. **09 安全性**：本文（安全性項目の一覧・注記）で十分に厚く説明しているため、図解を割愛した。
8. **10 まとめ**：文章量が十分にあるため、あらためて図解を追加する必要はないと判断した。
